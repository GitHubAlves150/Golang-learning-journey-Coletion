## ✅ O que este código te ensina  
```go
CAMADAS             CONCEITO                                        OQUE VOCÊ APRENDEU

Rotas               HandleFunc                                      Como organizar endpoint RESTful
GET                 /summaries                                      Listar todos os recursos
GET                 /summaries/{id}                                 Buscar um recurso específico
POST                /summaries                                      Criar um novo recurso
PUT                 /summaries/{id}                                 Atualizar um resurso exisitente
DELETE              /summaries/{id}                                 Remover um recurso
Path params         Extrair ID da URL                               string.split e strconv.Atoi
Status HTTP         201 Created, 204 No Content, 404 Not Found      Códigos de resposta apropriados

```
